# Eco Direito

Sistema da Awer para a Eco Direito Ambiental: prazos dos processos na Secretaria do Verde (SP) e financeiro.

```bash
npm install
npm run dev        # http://localhost:3000
```

Para congelar a data numa apresentação, crie `.env.local` com `DATA_DEMO=2026-11-03`.

Contexto do projeto (leia antes de mexer): [CLAUDE.md](CLAUDE.md) e a pasta [context/](context/).
